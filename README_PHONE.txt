КАК ОТКРЫТЬ НА ТЕЛЕФОНЕ

Важно: для установки как приложения PWA папку нужно открыть через обычный веб-адрес (HTTPS).
Если просто открыть index.html из приложения «Файлы», каталог будет работать, но кнопка «Добавить на главный экран» может быть недоступна.

iPhone:
1. Разместите эту папку на любом HTTPS-хостинге.
2. Откройте index.html в Safari.
3. Поделиться → На экран «Домой».
4. После первого открытия основные данные кэшируются; просмотренные видео также сохраняются в кэш.

Android:
1. Откройте сайт в Chrome.
2. Меню ⋮ → «Установить приложение» / «Добавить на главный экран».

В каталоге есть:
— мобильная верстка;
— поиск и фильтры;
— избранное, сохраняющееся на устройстве;
— MP4-видео, совместимые с iPhone и Android;
— офлайн-кэш.
