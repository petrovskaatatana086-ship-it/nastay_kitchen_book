# Nasti Kitchen — GitHub Pages

## Как опубликовать

1. Создайте новый публичный репозиторий на GitHub, например:
   `nasti-kitchen`

2. Загрузите **содержимое этой папки** в корень репозитория.
   В корне обязательно должны лежать:
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
   - папка `media`
   - файл `.nojekyll`

3. Откройте:
   **Settings → Pages**

4. В разделе **Build and deployment** выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`

5. Нажмите **Save**.

Через некоторое время GitHub покажет адрес сайта вида:

`https://ВАШ-ЛОГИН.github.io/nasti-kitchen/`

## На телефоне

### iPhone
Откройте сайт в Safari → Поделиться → **На экран «Домой»**.

### Android
Откройте сайт в Chrome → меню → **Установить приложение** / **Добавить на главный экран**.

Все пути в проекте относительные, поэтому сайт рассчитан на GitHub Pages внутри репозитория, а не только на корневой домен.


## Новые функции этой версии

- Избранное группируется по категориям.
- На каждой карточке есть кнопка ✎ для редактирования.
- Можно изменить название, категорию, ингредиенты и приготовление.
- Правки автоматически сохраняются в браузере телефона.
- Через раздел «Данные» можно экспортировать правки и избранное в JSON.
- JSON можно импортировать на другом устройстве.
- «Сбросить все правки» возвращает исходные рецепты.

Важно: GitHub Pages — статический сайт. Изменения, сделанные в приложении, не меняют файлы репозитория и видны только в браузере, где были сохранены. Для переноса используйте экспорт/импорт.


## Дополнительно в версии Plus

### Пересчёт порций
На карточке можно менять количество порций. Если известно исходное количество порций, укажите его через ✎ «Редактировать». Если оно неизвестно, приложение использует множитель 0,5× / 1× / 2×. Числовые количества рядом с обычными единицами измерения пересчитываются автоматически.

### Режим «Готовить»
Кнопка «Готовить» открывает полноэкранный режим:
- ингредиенты с галочками;
- один шаг приготовления на экране;
- «Назад» / «Дальше»;
- попытка не выключать экран через Screen Wake Lock API, если браузер это поддерживает.

### Личные заметки
Заметка у каждого рецепта автоматически сохраняется только на текущем устройстве.

### Свои фотографии
Фото можно сделать камерой телефона или выбрать из галереи. Перед сохранением изображение уменьшается и сжимается. Фото хранятся локально в IndexedDB браузера.

ВАЖНО: свои фото не входят в JSON-резервную копию и не синхронизируются через GitHub Pages. Очистка данных сайта в браузере удалит локальные фото, заметки, правки и избранное.
